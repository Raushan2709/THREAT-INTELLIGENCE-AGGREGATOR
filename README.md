# Threat Intelligence Aggregator

## Overview
The **Threat Intelligence Aggregator** is a Python-based cybersecurity tool designed for Security Operations Center (SOC) analysts and threat hunters. It automates the retrieval and normalization of live Indicators of Compromise (IoCs)—including IP addresses, domains, and file hashes—from major threat intelligence platforms such as **VirusTotal API v3** and **AlienVault Open Threat Exchange (OTX)**.
